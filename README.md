# luci-app-vpnswitch — готовые пакеты

Версия: **2.17.86-r1**

Сюда автоматически кладётся последняя сборка: `luci-app-vpnswitch.apk` и `version.txt`.
Роутеры с VPN-переключателем раз в сутки проверяют `version.txt` и обновляются по кнопке в LuCI.

## Зеркало

Для роутеров без доступа к github.com:

- `fb/` — [File Browser](https://github.com/filebrowser/filebrowser) (Apache-2.0, лицензия в `fb/LICENSE`), без изменений.
- `awg/` — копия APK-фида [awg-openwrt](https://github.com/Slava-Shchipunov/awg-openwrt) без изменений; исходный код — там же.
